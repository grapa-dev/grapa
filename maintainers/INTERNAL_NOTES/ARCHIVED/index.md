## Archive Policy

### **When to Archive**
- Documentation has been superseded by newer, more comprehensive versions
- Features or systems have been deprecated or replaced
- Work-in-progress documentation is no longer relevant
- Consolidation efforts have moved content to canonical locations

### **Archive Maintenance**
- Archives are kept for historical reference and context
- No active maintenance is performed on archived content
- Archives may be referenced for historical context or research
- Archives are not included in active documentation navigation

## How to Use Archives

### **Historical Research**
- Archives provide context for how systems and documentation evolved
- Historical decisions and rationale can be found in archived content
- Previous approaches and solutions are documented for reference

### **Context for Changes**
- Archives help understand why certain changes were made
- Historical problems and solutions are preserved
- Evolution of documentation structure is traceable

### **Reference for Similar Issues**
- Historical bug investigations may provide insights for similar current issues
- Previous approaches to problems can inform current solutions
- Historical documentation patterns can guide current documentation
