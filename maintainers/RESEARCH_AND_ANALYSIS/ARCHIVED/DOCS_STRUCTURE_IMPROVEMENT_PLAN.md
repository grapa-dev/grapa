## Remaining Action Items (2024)

- [ ] **Add a visual map/diagram to the About or Home page**
    - A visual overview of the documentation structure and Grapa architecture will further help new users.
- [ ] **Audit and improve cross-linking between major sections**
    - Ensure all major sections (API Reference, Language Reference, Use Cases, Examples) cross-link to each other where relevant.
    - Add “See also”/“Related topics” to key pages for better discoverability.
- [ ] **Create/expand “Advanced Topics” section if needed**
    - If new advanced features (meta-programming, custom grammar, etc.) are added, ensure they are documented in a dedicated section.
- [ ] **Periodically review maintainer/internal docs for separation**
    - Ensure no internal details leak into user-facing docs as new content is added.
