# DEVELOPMENT Folder – Start Here

Welcome to the `maintainers/DEVELOPMENT/` folder!

This directory contains all in-progress, investigation, planning, and debug documentation for the Grapa project. If you are working on a bug, planning a new feature, or tracking ongoing work, you are in the right place.

**Start with:**
- [`CURRENT_STATUS.md`](CURRENT_STATUS.md) – The single source of truth for all active work, priorities, and progress.
- [`index.md`](index.md) – Full navigation and summaries for all development docs, including backlogs, roadmaps, and investigations.

**How to add a new investigation or planning doc:**
1. Check if your topic fits as a section in an existing doc (especially `CURRENT_STATUS.md`).
2. If not, create a new file in this folder, add a one-line summary to `index.md`, and cross-link from any relevant implementation docs.
3. Follow the contributor checklist in `index.md` for naming, placement, and cross-linking.

**Tip:**
- For canonical, stable implementation references, use the `IMPLEMENTATION/` folder instead.
- Archive completed or superseded docs in `INTERNAL_NOTES/ARCHIVED/` and update the index.

For more details, see the contributor checklist in `index.md`.
