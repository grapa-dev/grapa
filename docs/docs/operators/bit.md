# Bit Operators
## `<<` number
Bit shift left. An effet of multiplying by 2 for every bit shifted.

## `>>` number
Bit shift left. An effect of dividing by 2 for every bit shifted.

## `|`
Bitwise or.

## `&`
Bitwise and.

## `^`
Bitwise xor.
