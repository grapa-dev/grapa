# Math Operators
## `+`
Add.

## `-`
Subtract.

## `**`
Power.

## `*/`
Root.

```
> (9*9) */ 2
9

> (9*9) */ 2.0
9

> (9*9) */ 2.1
8.105921431777598477594162942004

> (9*9) */ 4.0
3

> (9*9) ** 0.5
9

> (9*9) ** 0.25
3
```


## `*`
Multiply.

## `/`
Divide.

## `%`
Mod.
